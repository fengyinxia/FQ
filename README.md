# FuckTomato

面向番茄免费小说（`com.dragon.read`）的 Xposed 模块，用于精简界面、屏蔽干扰内容并保留常用阅读与下载体验。所有功能均可在宿主内的 **FQ 插件设置** 页面中开关。

## 功能

设置页入口位于番茄自身设置列表（原生与 KMP 页面均支持），开关保存后重启番茄生效。

- **内容屏蔽**：拦截广告；**Banner控制**按书架实际返回类型发现并逐项屏蔽；**弹窗控制**按宿主弹窗 ID 统一发现并逐项屏蔽，不按功能性标记或名称自动豁免；仅拦截用户勾选项，新弹窗默认不勾选；按业务类型发现并屏蔽推荐流项目，动态过滤搜索分类与对应结果。选择保存后重启生效，不预填未出现项目。
- **UI 净化**：隐藏我的页钱包、会员、快捷入口与推荐卡片；“我的页 → 红点”控制原生/KMP快捷入口、侧栏未读角标及底栏小红点、数字/文字/图片角标（不修改真实未读状态）；精简书城顶部频道；清理搜索推荐词与热榜；内容净化可选“热门评论”“章末区域”“疯癫榜”（将封面巅峰榜区域恢复为正常评分/点评UI，保留其他统计）；侧栏入口改为设置；**强制原书名**可独立选择封面、推荐、书架及主页顶部“小说”频道；推荐/小说数据同时替换完整名与短名，并适配已确认的单书动态模板标题；书架仅在已观察到同 bookId 的可信小说原名时替换原生展示名称，无可信原名则保留现有书名（封面沿用文字模式），不主动请求详情；搜索不再参与原书名替换。书架不修改数据库，尚不覆盖 KMP 桥接和所有布局。
- **拓展**：底栏自定义（显隐、长按拖拽排序、主页同框编辑）；下载时可选缓存或缓存并导出 TXT；支持屏蔽宿主更新。
