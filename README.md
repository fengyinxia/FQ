# FuckTomato

面向番茄免费小说（`com.dragon.read`）的 Xposed 模块，用于精简界面、屏蔽干扰内容并保留常用阅读与下载体验。所有功能均可在宿主内的 **FQ 插件设置** 页面中开关。

## 适配版本

| 项目 | 版本 |
| --- | --- |
| 番茄免费小说 `com.dragon.read` | **7.4.3.32**（官网渠道） |
| 模块 | 2.4.8（20408） |
| 运行环境 | Android 10（API 29）及以上，LSPosed / Xposed |

仅以官网 7.4.3.32 为适配基线，不保证旧版或其他渠道兼容；宿主升级后 Hook 目标可能失效。
