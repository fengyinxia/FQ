# FuckTomato

面向番茄免费小说（`com.dragon.read`）的 Xposed 模块，用于精简界面、屏蔽干扰内容并保留常用阅读与下载体验。所有功能均可在宿主内的 **FQ 插件设置** 页面中开关。

## 功能

设置页入口位于番茄自身设置列表（原生与 KMP 页面均支持），开关保存后重启番茄生效。

- **内容屏蔽**：拦截广告、书架短剧 Banner、运营弹窗；按业务类型发现并屏蔽推荐流项目；动态过滤搜索分类与对应结果，未识别内容默认放行。
- **UI 净化**：隐藏我的页钱包、会员、快捷入口、推荐卡片与红点；精简书城顶部频道；清理搜索推荐词与热榜；隐藏章末社区和封面热门评论；侧栏入口改为设置，封面显示完整书名。
- **拓展**：底栏自定义（显隐、长按拖拽排序、主页同框编辑）；下载时可选缓存或缓存并导出 TXT；支持阅读器返回行为、屏蔽宿主更新与 AB 配置更新、上报与推送控制。
